# Cast

Ouvre une vidéo, puis clique sur Caster dans la barre du lecteur. Le plein écran se ferme pour afficher le choix de l’appareil. Choisis un appareil ou le mode navigateur. Slyorrent prépare une copie compatible si nécessaire et conserve l’original.

Avec le mode navigateur, ouvre l’adresse affichée sur l’autre écran et saisis le code du PC. Il expire après deux minutes et ne peut servir qu’une fois. Certains navigateurs demandent d’appuyer sur Lire au premier démarrage.

Pendant le cast, une vue de suivi affiche l’appareil, la préparation, l’épisode et sa position. Les commandes restent sur le PC : pause, reprise, déplacement, volume si disponible, audio et sous-titres. La file de lecture indique l’épisode en cours et ceux qui suivent ; tu peux en choisir un directement. Elle reste accessible en revenant dans la médiathèque.

L’option Épisode suivant automatique prépare le prochain fichier et le lance à la fin. La position de lecture reste enregistrée sur le PC, comme avec le lecteur local. L’enchaînement s’arrête si le prochain fichier n’est plus validé ou si l’appareil se déconnecte. Un arrêt ou une erreur sur la TV laisse le suivi ouvert, avec l’épisode, la position et Réessayer. Le panneau se ferme avec Fermer ou Arrêter le cast. Le journal distingue un arrêt volontaire d’un refus de lecture et indique si le PC a reçu une demande de vidéo, sans enregistrer l’adresse du flux. La file est limitée à 250 fichiers, autour de l’épisode choisi.

Google Cast utilise le récepteur média standard. DLNA repose sur AVTransport ; selon la TV, les sous-titres séparés et le déplacement dans la vidéo peuvent être refusés. Un navigateur récent peut servir de lecteur sur une tablette, un téléphone ou un autre ordinateur. Les vidéos sont préparées en MP4 H.264/AAC, avec une conversion limitée à 1080p si nécessaire. La compatibilité de chaque modèle doit être vérifiée sur l’appareil. AirPlay et Miracast ne sont pas inclus.

Le PC et l’écran doivent rester allumés, sur le même réseau privé. Un réseau invité peut isoler les appareils. Si Windows demande une autorisation, n’autorise Slyorrent que sur les réseaux privés. L’application ne désactive pas le pare-feu et n’ouvre aucun port sur la box. Le Wi-Fi du PC et celui de l’écran doivent pouvoir communiquer ; un VPN peut aussi empêcher la découverte.

Le partage est limité à l’appareil choisi et aux médias en cours de lecture ou de préparation. Il n’expose ni le disque ni toute la bibliothèque. Les fichiers gardent la validation du lecteur local et les copies passent par Defender. Le flux vidéo n’est pas chiffré : ce mode est prévu pour un réseau de confiance.
