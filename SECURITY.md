# Signaler un problème de sécurité

N’ouvre pas d’issue publique si le problème peut exposer un fichier local, une adresse, une passkey, un chemin personnel ou permettre l’exécution de code.

Utilise plutôt **Security > Report a vulnerability** sur GitHub. Indique la version de Slyorent, Windows, ce que tu as fait, ce qui s’est passé et un moyen simple de reproduire le problème. Ne joins aucun torrent privé, magnet réel, passkey, média personnel ou journal non nettoyé.

La V1 reçoit les corrections de sécurité critiques. Une confirmation sera donnée après reproduction, puis le correctif sera publié avant les détails complets quand le risque le demande.
